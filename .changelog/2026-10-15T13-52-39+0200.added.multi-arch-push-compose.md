# Add _push.yml for amd64 and arm64 Hub publishes

Local builds stay on `_build.yml` (single-arch, loadable into the engine). Hub
publishes need a self-contained compose file with `platforms: linux/amd64` and
`linux/arm64` for both `model-download` and `flash-next`, matching the sibling
stack pattern so `docker compose -f _push.yml build --push` can publish
multi-arch manifests without merging into the local build file.
