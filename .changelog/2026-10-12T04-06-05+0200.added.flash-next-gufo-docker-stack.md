Added a Docker Compose stack that builds [mikealanni/gufo](https://github.com/mikealanni/gufo) from `src/flash-next/Dockerfile` on Ubuntu 24.04 with ROCm gfx1151, XRT headers from `ppa:amd-team/xrt` (required for this fork’s NPU-linked binary), and serves Qwen3.8 Flash-Next via `scripts/run-gufo.sh` with model mounts and optional Cloudflare tunnel networking.
