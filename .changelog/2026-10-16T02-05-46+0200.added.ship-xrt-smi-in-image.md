# Ship xrt-smi in the flash-next image

Install `libxrt-utils` and `libxrt-utils-npu` so `/usr/bin/xrt-smi` is
available for the NPU turbo-mode guard. The serve script now resolves
`xrt-smi` from `$XRT_DIR/bin` or `PATH`, and the troubleshooting doc covers
setting `performance`/`balanced` from the container.
