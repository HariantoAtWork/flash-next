# Pass GPU devices into the fabric-clock container

`fabric-clock` is a separate privileged one-shot. Pinning `pp_dpm_fclk` only
needs amdgpu sysfs, but without `/dev/kfd` and `/dev/dri` that sysfs can be
unreliable in some Docker setups. Pass those devices on the service (leave
`/dev/accel` on `flash-next` only) and document hold-failure checks.
