# Gate model-download behind compose profile init

`model-download` is a one-shot weight fetcher, not a long-running service. It
now declares `profiles: [init]` in the compose example so plain `compose up`
only starts `flash-next`. `./dc.sh download` passes `--profile init` to enable
it; `_build.yml` build of `model-download` during `init` is unchanged.
