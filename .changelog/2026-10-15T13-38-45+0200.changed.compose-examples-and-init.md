# Ship compose files as examples with dc.sh init

Local `docker-compose.yml` and `docker-compose.override.yml` are host-specific
(tsdproxy labels, ports), so they should not be committed as the only copy.

They are renamed to `*.example`, ignored by git when materialised, and created
via `./dc.sh init` (all `*.example` except override, including `.env.example`)
and `./dc.sh init:override` (tsdproxy override only). Runtime commands now load
the override only when the local file exists.
