# Add docker compose helper script dc.sh

The stack needs several `docker compose` invocations with different file
combinations (`_build.yml` for builds, `docker-compose.yml` plus the tsdproxy
override for runtime), plus a long model-load wait after start.

`dc.sh` wraps these into one documented entrypoint with subcommands for
`build`, `download`, `up`, `down`, `restart`, `ps`, `logs`, `run`, `pull` and
`config`, selects the correct compose file set per command, and polls the
`/v1/models` endpoint after `up`/`restart` so users get a clear ready signal
instead of guessing when the model has finished loading.
