# Document GUFO_CONTEXT serve context window

The serve context window (`GUFO_CONTEXT`, default `131072` = 128K tokens) was
only visible inside `docker-compose.yml`, so users hitting "max tokens
exceeded" had no way to discover the knob.

Documented it in the README (Environment table + Notes) with the model maximum
of `262144` (256K) and a warning that KV-cache memory scales with the window,
added a commented `GUFO_CONTEXT` example to `.env.example`, and added inline
comments at the `GUFO_CONTEXT` lines in both `docker-compose.yml` and
`docker-compose.yml.example`.
