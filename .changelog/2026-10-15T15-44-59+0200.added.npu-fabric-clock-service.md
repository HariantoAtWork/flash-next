# Add one-shot fabric-clock service for NPU path

Enable the XDNA2 NPU path through Compose instead of a manual privileged
`docker run`. A new `fabric-clock` service runs `fabric-clock.sh hold` to pin
the GPU fabric clock before `flash-next` starts (`depends_on`
`service_completed_successfully`), and `/dev/accel/accel0` is passed through so
`docker-serve.sh` enables NPU when `GUFO_NPU != 0`. GPU-only (`GUFO_NPU=0`) is
unchanged; the clock resets at reboot and is not auto-released on `down`.
