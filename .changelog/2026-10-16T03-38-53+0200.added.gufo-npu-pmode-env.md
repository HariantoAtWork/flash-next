# Apply NPU power mode from GUFO_NPU_PMODE

`docker-serve.sh` now runs `xrt-smi configure --pmode` at serve start when
`GUFO_NPU_PMODE` is set (performance/balanced/default/powersaver; turbo
refused), so power mode no longer needs a manual post-start docker exec.
Wired through compose and documented in the README / NPU troubleshooting.
